Installing on Android

Three taps and you are in

  1. 1
    Download the APKTap the button above, or scan the QR code with your phone's camera.
  2. 2
    Allow the installAndroid asks to allow apps from this source. Tap Settings, switch on Allow from this source, then go back.
  3. 3
    Open and installTap the downloaded file, then Install. Find Ethio Build Connect in your app drawer.

Updating from an earlier preview? Uninstall the old app first. Earlier previews were signed with a temporary key, so Android will not install this version over them. From this version on, updates install in place.

Direct download. This build is distributed from ethiobuildconnect.et rather than Google Play. Live video needs a network connection to the exhibition server.
